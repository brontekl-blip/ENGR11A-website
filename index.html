Design Project #1

Part 1: Customized Name Tag

We started class by downloading and setting up prusaslicer, and then played with settings for a bit before slicing it and downloading the G code to a USB drive and bringing it to the printers. We used the Prusa MINIs with Input Shapers and PLA, which are the same machines and filament I used in all prints for this project. I purposefully chose a funky font, “Old English,” to see how well the printer would do, and it did mess up a bit, with the smaller details of the letters being lost. Figuring out how to load the filament was a little tricky, and we changed colors part of the way through so I had to unload and reload the filament. Overall, I think the print was pretty successful.

Part 2: The Benchy Torture Test

It took a few minutes to download the right file so that I could edit the type of filament and printer. It seems like after looking into it a bit, .stl files are less customizable and store less information about the intended end result of the print compared to .mpf files that can contain things like intended colors. I started the print at the end of a class and picked it up off the printer at the beginning of the next, and it seems to have printed without any major flaws/errors. In the pictures below you can see some “stringing” when transitioning from one area of the print to another, the minor flaws in the finer details, as well as the less-sleak aligned seams on the two cylinders of the build. This is a good demonstration of the limits of 3D printing objects without harsh edges, and how you might need to use a different seam technique, such as randomized, depending on the geometry of what you print. The arches and pot windows seem to have had the hangovers created at enough of an angle to maintain their desired shapes without dripping.

Part 3: Open Source Assistive Devices

The 3D printable assistive device I found was Flipper the Clipper, a one-handed tool to simplify the use of nail clippers for people who may struggle with grip strength, hand steadiness, etc. The designer was nisker_ on Thingiverse, who adapted it from designer SONOKO’s original idea but to have an integrated hinge and be easier to 3D print. It was a single print that took about an hour, which was less than the 3.5 hours predicted by the listing. A design flaw I noticed while trying to use it was that the hinge area is too narrow for most nail clippers, as can be seen in the first few photos of the printed version below, and should probably be adjusted to accommodate a wider variety of sizing. After taking another look, the post on Thingiverse recommends using Onshape to customize the design to fit your own nail clippers.

Part 4: Personal Website

The final part of our assignment was designing a website to upload our class projects to, using BootStrap and GitHub. We started by watching tutorials on the basics of coding a website with BootStrap, such as common coding language and boundaries. We then spent some time in class for troubleshooting, but most of the website building was done outside of class in my case. Since we had templates, it was relatively easy to just replace the images and texts with my own, but sizing and spacing is still a struggle as you might be able to tell from the initial iteration of this project’s upload (hopefully I will be able to go back and fix this later down the line).
